# Changelog | تغییرات

## 1.0.0 — 2026-10-12

Initial Android implementation / نسخه اولیه اندروید:

- Account CRUD, name search, categories, expiry filters, cost and optional credentials.
- Solar Hijri dates, anchored monthly/yearly renewals, and 7/3/1-day reminders.
- AES-GCM vault, passphrase derivation, biometric key wrapping and master-key rotation.
- Encrypted backup/import, local password generator, automatic foreground-exit lock.
- Six palettes, light/dark appearance, Persian RTL interface and Vazirmatn fonts.
- Public-source documentation, MIT license, contribution and security policies, issue/PR templates, and CI configuration.

Desktop support, synchronization, an independent audit and verified real-device background delivery are not part of this release.
