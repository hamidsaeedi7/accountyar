# Community code of conduct | اصول رفتار جامعه

AccountYar welcomes contributors of all backgrounds. Communicate respectfully, assume good intent, and critique ideas and code rather than people. English and Persian contributions are equally welcome.

Harassment, discriminatory language, threats, unwanted personal contact, publishing another person's private information, and knowingly posting real credentials are not acceptable. Do not use issues or pull requests to target individuals or promote unrelated services.

Maintainers may edit or remove inappropriate content, close disruptive discussions, or restrict participation. Enforcement is proportionate and handled with attention to privacy. This policy applies to repository issues, pull requests, reviews, and other project-managed spaces.

Report community concerns using an available private maintainer contact channel. If none is established, request a private channel in an issue without naming affected people or exposing sensitive details. Security reports follow [SECURITY.md](SECURITY.md).

## فارسی

مشارکت همه افراد با پیشینه‌های مختلف پذیرفته است. با احترام گفتگو کنید و کد و ایده را نقد کنید. مشارکت فارسی و انگلیسی ارزش یکسان دارد.

آزار، تبعیض، تهدید، تماس شخصی ناخواسته، انتشار اطلاعات خصوصی دیگران و قرار دادن عمدی رمزهای واقعی پذیرفته نیست. نگهدارنده می‌تواند محتوای نامناسب را اصلاح یا حذف کند، گفتگو را ببندد یا مشارکت مخرب را محدود کند.

نگرانی رفتاری را از مسیر خصوصی در دسترس گزارش دهید؛ اگر چنین مسیری تعیین نشده، بدون افشای افراد و اطلاعات حساس، درخواست کانال خصوصی کنید. گزارش امنیت طبق SECURITY.md انجام می‌شود.
